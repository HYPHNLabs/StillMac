# Acknowledgements

StillMac is an independent implementation built from its documented product and privacy requirements. No source code from the internal exploratory prototype was copied into the Go implementation.

The product grew from HYPHN Labs' own seven-day, observe-only experiment measuring local development-tool and agent activity before considering any cleanup action. The public implementation was written separately from that exploratory collector.

Third-party runtime dependencies: none. The current implementation uses the Go standard library and macOS native utilities documented in the tracer contract.
