# StillMac v0.1 tracer contract

## Product boundary

StillMac v0.1 includes a local, deterministic macOS process and memory baseline. This tracer surface exposes four commands:

- `stillmac doctor` checks the host, required native commands, and the selected local data directory.
- `stillmac sample` collects one observation and atomically appends it to immutable private history. It does not create or update the legacy compatibility file.
- `stillmac status` emits the current baseline/readiness status as JSON.
- `stillmac report --format json|markdown` renders the latest validated sample to standard output.

This tracer surface remains read-only and backward compatible. The same binary also exposes the separately contracted developer-cache commands in [DEVELOPER-CLEANUP-CONTRACT.md](DEVELOPER-CLEANUP-CONTRACT.md). Those commands do not change this tracer's schemas, collection fields, report semantics, or four existing command behaviours.

There is no scheduler, network access from the Go binary, telemetry, LLM integration, process action, port inspection, or background service. Cleanup action is limited to the separate contract. Distribution scripts and a thin Agent Skill are present, but remote release activation is absent. A future release installer alone would use the network to fetch a versioned release asset and manifest; StillMac writes no log file.

macOS 14+ is the target. This contract does not claim macOS 14 support; that remains pending verification on a real macOS 14 host.

## Data boundary

Each process observation contains only these allowlisted fields:

| Field | Meaning |
|---|---|
| `comm` | Sanitised executable basename or kernel command label, limited to 64 ASCII letters, digits, `.`, `_`, `+`, and `-` |
| `pid` | Process ID at collection time |
| `ppid` | Parent process ID at collection time |
| `cpu_percent` | The numeric `%cpu` value reported by `ps`; it may exceed 100 on a multi-core system |
| `memory_percent` | The numeric `%mem` value reported by `ps` |
| `elapsed_seconds` | The `ps` elapsed value converted to whole seconds |

The host observation also contains:

| Field | Meaning |
|---|---|
| `captured_at` | UTC collection time in RFC 3339 format |
| `memory.pressure` | `normal`, `warning`, or `critical` |
| `memory.swap_used_bytes` | Swap currently used, converted to bytes |
| `quality` | Validity, accepted/rejected row counts, input availability, and fixed issue codes |

StillMac invokes `/bin/ps` with only `pid`, `ppid`, `%cpu`, `%mem`, `etime`, and `ucomm` output columns. The stored JSON field remains `comm`. The parser reads the fixed five numeric/time columns first and treats the complete remaining `ucomm` column as one label. It isolates the executable or accounting basename before removing any command-like suffix and applying the `comm` allowlist. Option-looking text in a parent path component is never treated as a suffix. This preserves labels containing spaces without persisting a directory or workspace fragment. It invokes `/usr/sbin/sysctl` only for the memory-pressure level and swap usage keys. `comm` is the sole executable label allowed by this contract; unrelated filesystem filenames are prohibited.

Accepted `ps` elapsed forms are exactly `mm:ss`, `hh:mm:ss`, and `days-hh:mm:ss`, with two digits for hours, minutes, and seconds. A day-prefixed form without all three time components is invalid. Values above 9,223,372,036,854,775,807 seconds are rejected.

StillMac never collects or stores:

- command arguments or command lines;
- environment variables;
- full executable paths;
- workspace paths or names;
- usernames;
- unrelated filenames or file contents;
- clipboard or browser data;
- agent or chat content;
- tokens, API keys, passwords, or credentials;
- cache contents or port data. The cleanup scanner records only allowlisted root metadata under its separate schema.

Native command output and errors are not copied into state, reports, logs, or user-visible errors. User-visible errors are fixed, path-free messages.

## Process identity semantics

`pid` is an observation-local identifier. macOS can reuse a PID, so a PID does not identify the same process across samples. `comm` is a lossy label, not a stable identity and not proof that two observations describe the same executable. `ppid` is also valid only at collection time. StillMac performs no cross-sample identity matching.

## Memory semantics

StillMac reads `kern.memorystatus_vm_pressure_level` and maps native values `1`, `2`, and `4` to `normal`, `warning`, and `critical`. Any other value invalidates the sample. It reads `vm.swapusage`, validates the complete native shape and the complete `used` token, and converts optional `B`, `K`, `M`, `G`, or `T` units with binary multiples to bytes. Unsupported units, malformed or contaminated tokens, and values that overflow an unsigned 64-bit byte count invalidate the sample.

Process collection and the two memory reads happen sequentially in one collection cycle. They are temporally associated, not perfectly simultaneous. StillMac never claims that a process caused a memory-pressure condition or swap usage.

## Valid sample and data-quality rules

A sample is valid only when:

1. the process command succeeds and at least one row passes validation;
2. every stored process has a positive PID, non-negative PPID, finite non-negative CPU value, memory value from 0 through 100, non-negative elapsed seconds, and a safe non-empty `comm`;
3. the memory-pressure command succeeds with a recognised condition;
4. swap usage succeeds and parses to a non-negative byte count;
5. `captured_at` is canonical UTC RFC 3339.

An invalid process row is discarded. If at least one row remains, the sample is valid with `quality.status` set to `degraded`, the rejected count recorded, and the fixed issue code `process_rows_rejected`. A sample with no rejected rows is `complete`. A failed or incomplete sample is never written over the last valid state.

## Preliminary report and confidence

Every tracer report is explicitly `preliminary`. Coverage is exactly one valid sample with an observed span of zero seconds. Confidence is `low` because one instantaneous sample cannot establish a baseline or trend. Reports repeat this interpretation limit:

> Observed process and memory measurements are temporally associated within one collection cycle. They do not establish that any process caused memory pressure.

## Local state and retention

The default data directory is `$HOME/Library/Application Support/StillMac`. Every command accepts `--data-dir` to select another directory. StillMac creates or re-permissions the selected storage directory to mode `0700`; state and history files use mode `0600` and are written atomically.

A selected data directory that is itself a symbolic link is rejected. Reads and writes reject a symbolic link or non-regular object at the state-file path. StillMac opens the selected directory without following the final path component, retains and rechecks that directory handle around path operations, and opens the state file with no-follow semantics. These checks reduce path-swap races using the Go standard library available on the target. A failed write leaves the last valid regular state file unchanged.

State writes reject an encoded state larger than 8 MiB before replacing the previous valid state. State reads reject `current-sample.json` before decoding when its file size exceeds 8 MiB. History accepts at most 672 newest samples, no older than 14 days, with a 128 MiB total bound and a 2 MiB per-sample bound. The decoder requires every documented state, sample, process, memory, and quality member, including members whose valid value is zero or an empty array. It also rejects unknown fields, a second JSON value, and any trailing non-whitespace content.

Each successful sample is an immutable history entry. History is bounded to the newest 672 entries, 14 days, 128 MiB total, and 2 MiB per sample; an append prunes only entries outside those bounds. An older valid `current-sample.json` remains readable and is merged for compatibility, but current sampling does not create or update it. Reports are emitted to standard output and are not retained by StillMac. There is no automatic cleanup scheduler. The separate cleanup contract supports one explicit owner-native Go build cache action. The uninstaller removes only the binary and retains data; retention enforcement occurs during accepted storage operations, and the caller owns removal of the selected data directory.

`doctor` may create the selected data directory and a short-lived `0600` write probe inside it. It rejects a symbolic link or non-regular object already present at the state-file path, removes the probe, and does not alter system configuration.

`doctor` executes only these fixed, safe native probes:

- `/bin/ps -p 1 -o pid=` and requires one positive numeric PID;
- `/usr/sbin/sysctl -n kern.memorystatus_vm_pressure_level` and requires `1`, `2`, or `4`;
- `/usr/sbin/sysctl -n vm.swapusage` and requires the recognised swap shape described above.

Native standard output is parsed in memory and discarded. Native standard error is suppressed. Neither is copied into the JSON result or user-visible errors. A failed or denied probe produces a generic failed check; StillMac does not assume sandbox restrictions are normal product behavior.

## JSON shapes

Stored state uses `stillmac.state.v1`:

```json
{
  "schema_version": "stillmac.state.v1",
  "sample": {
    "schema_version": "stillmac.sample.v1",
    "captured_at": "2026-08-07T12:00:00Z",
    "processes": [
      {
        "comm": "example",
        "pid": 123,
        "ppid": 1,
        "cpu_percent": 1.5,
        "memory_percent": 0.25,
        "elapsed_seconds": 90
      }
    ],
    "memory": {
      "pressure": "normal",
      "swap_used_bytes": 0
    },
    "quality": {
      "valid": true,
      "status": "complete",
      "process_rows_observed": 1,
      "process_rows_accepted": 1,
      "process_rows_rejected": 0,
      "memory_pressure_available": true,
      "swap_used_available": true,
      "issues": []
    }
  }
}
```

JSON reports use `stillmac.report.v1`:

```json
{
  "schema_version": "stillmac.report.v1",
  "status": "preliminary",
  "preliminary": true,
  "confidence": {
    "level": "low",
    "basis": "one valid instantaneous sample cannot establish a baseline or trend"
  },
  "coverage": {
    "valid_samples": 1,
    "observed_span_seconds": 0,
    "captured_at": "2026-08-07T12:00:00Z"
  },
  "data_quality": {
    "valid": true,
    "status": "complete",
    "process_rows_observed": 1,
    "process_rows_accepted": 1,
    "process_rows_rejected": 0,
    "memory_pressure_available": true,
    "swap_used_available": true,
    "issues": []
  },
  "memory": {
    "pressure": "normal",
    "swap_used_bytes": 0
  },
  "processes": [],
  "interpretation": "Observed process and memory measurements are temporally associated within one collection cycle. They do not establish that any process caused memory pressure."
}
```

The `processes` array in a real report contains the same allowlisted process objects as state. The empty array above keeps the contract example short.

Successful doctor summaries use the stable `stillmac.doctor.v1` schema:

```json
{
  "schema_version": "stillmac.doctor.v1",
  "status": "ready",
  "checks": [
    {
      "name": "operating_system",
      "status": "pass",
      "detail": "macOS detected"
    },
    {
      "name": "native_command:ps",
      "status": "pass",
      "detail": "required native probe succeeded"
    },
    {
      "name": "native_command:sysctl",
      "status": "pass",
      "detail": "required memory probes succeeded"
    },
    {
      "name": "data_directory",
      "status": "pass",
      "detail": "local data directory is writable"
    }
  ]
}
```

`status` is `ready` only when all four checks pass; otherwise it is `not_ready`. A check `status` is `pass` or `fail`. Check names and generic details are fixed and path-free. The single `native_command:sysctl` check covers both required sysctl probes.

`status` emits `stillmac.status.v1`. It reports a seven-day target, 30-minute expected interval, 7 minimum observed days, and 84 minimum coverage intervals. It is always read-only and never enables recommendations. Its stable fields are `status`, those four baseline constants, `valid_samples`, `coverage_intervals`, `observed_days`, `observed_span_seconds`, `progress_percent`, `largest_gap_seconds`, `first_captured_at`, `last_captured_at`, `complete_samples`, `degraded_samples`, and `blockers`. `status` is `collecting` until all blockers are cleared, then `coverage_ready`; blockers use fixed codes such as `span_incomplete`, `observed_days_insufficient`, and `coverage_insufficient`.

```json
{
  "schema_version": "stillmac.status.v1",
  "status": "collecting",
  "read_only": true,
  "recommendations_enabled": false,
  "target_span_seconds": 604800,
  "expected_interval_seconds": 1800,
  "minimum_observed_days": 7,
  "minimum_coverage_intervals": 84,
  "valid_samples": 1,
  "coverage_intervals": 1,
  "observed_days": 1,
  "observed_span_seconds": 0,
  "progress_percent": 0,
  "largest_gap_seconds": 0,
  "first_captured_at": "2026-08-07T12:00:00Z",
  "last_captured_at": "2026-08-07T12:00:00Z",
  "complete_samples": 1,
  "degraded_samples": 0,
  "blockers": ["span_incomplete", "observed_days_insufficient", "coverage_insufficient"]
}
```

Successful sample summaries use the stable `stillmac.sample-result.v1` schema:

```json
{
  "schema_version": "stillmac.sample-result.v1",
  "status": "stored",
  "sample_valid": true,
  "process_count": 1,
  "data_quality": "complete"
}
```

For a successful sample, `status` is `stored`, `sample_valid` is `true`, `process_count` is the number of stored process rows, and `data_quality` is `complete` or `degraded`.

## Markdown shape

Markdown reports contain, in order:

1. `StillMac preliminary report` heading;
2. preliminary status and low-confidence basis;
3. valid-sample coverage, `captured_at`, and data-quality status;
4. observed, accepted, and rejected process-row counts, both memory availability flags, and issue codes;
5. memory pressure and swap used;
6. a process table with only the six allowlisted process fields;
7. the temporal-association interpretation limit.

## Stable exit codes

| Code | Meaning |
|---:|---|
| `0` | Command completed successfully |
| `2` | Invalid command, option, or format |
| `3` | `doctor` found the host not ready |
| `4` | Sample collection failed or produced no valid sample |
| `5` | The default data directory could not be resolved, or local state could not be written, read, or validated |
| `6` | JSON or Markdown output could not be written |

Successful `doctor` and `sample` commands emit versioned JSON summaries. `report` emits the requested report format. Errors go to standard error and never include native output, the selected data path, or the rejected user input.
